Satellite Setup

Sets up Satellite on an Orbit Speak or Orbit Player: the Satellite Launcher, the Satellite hook, and Backtalk using the Orbit's keys. The Orbit does most of the work itself, restarting along the way, and says what it is doing.

1. Connect the Orbit

Connect the Orbit to this computer with a USB cable. It is found by itself.

Getting Android's tools ready. The first time, they are downloaded.

Connect with wireless debugging instead

On the Orbit, under Developer options, Wireless debugging: choose Pair device with pairing code, and enter the address and code it shows. Then enter the address shown under Wireless debugging itself, and connect.

2. Choose what setup does

Files from this computer to use instead of downloading them (you don't need any)

3. Set up

Keep the Orbit connected until setup says it is complete. It says on the Orbit what to answer when it asks something.

Progress

    Undo Satellite setup

    Puts the Orbit back as it was before Satellite was set up on it, and removes the Satellite Launcher.
